# S2 R13 — RuntimeParts (wstrzykiwalny korzeń kompozycji)

## Zrobione
- `include/loom/runtime.h`: addytywnie `PartsContext` (wskaźniki na to, co już zbudowane) i `RuntimeParts`
  (fabryki: http, analyzer, storage, models, providers, semantic_llm, memory, graph_memory, context, graph, chat,
  batch, worker, media, importer, crypto, github, embedding oraz archive/knowledge/actions budowane na końcu z `Runtime&`).
  `RuntimeOptions::parts` — puste sloty = domyślne. Istniejące konstruktory/`opts.http` działają bez zmian.
- `src/runtime.cpp`: `fill_default_parts()` odtwarza dotychczasowe okablowanie 1:1 (storage z fallbackiem, wczytanie
  manifestów providerów i dostawca zestawu kryptograficznego siedzą w fabrykach domyślnych); `open()` nie ma już
  `make_unique` dla portów, tylko `build_part()`. Zwrócony null z fabryki -> `Errc::Internal`.
  ActionRunner jest wstrzykiwalny jak każdy port (bez zmiany zachowania).
- Adaptery media/embedding/batch nie ruszane (R8) — konstrukcja tylko przez fabryki, wywołania bez zmian.
- Testy (`test_runtime.cpp`): podmiana http (fałszywy transport LLM), storage, semantic_llm i actions bez edycji
  runtime.cpp; null z fabryki; istniejący zestaw runtime = zachowanie domyślne.

## Decyzje
- Rdzeń (config, secrets, db, bus, event_log, blobs, provenance, tasks, relations, exporter) pozostaje niewymienny.
  Cofnięcie/rozszerzenie: dodać slot w `RuntimeParts` i wpis w `fill_default_parts`.
- `parts.http` ma pierwszeństwo przed `opts.http`. Cofnięcie: usunąć slot (opts.http dalej działa).
- Całość cofa się jednym `git revert` commita.

## Otwarte
- Brak osobnego slotu "vcs" (github jest slotem `github`); gdy R8 doda rejestr adapterów, fabryki media/embedding
  można zastąpić wywołaniem rejestru bez zmiany API `RuntimeParts`.
