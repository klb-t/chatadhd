  Leave the sealed holdout branch unchanged. Original branches/commits contain inputs, source,

- Promote reviewed implementation, contracts, native/web/Python tests, and exact
  fixtures needed by those tests. Preserve useful positive measurements with

- Main should expose one current state, this branch map, current contracts and a
  concise result summary. Parallel run dumps, obsolete STATE snapshots, old
  allocation plans and receipts stay in the archive. Old direct-main work is
  exempt from this pruning by the owner's explicit rule.

## Reproduce this audit

The JSON manifest pins all 37 live remote tips, parent SHAs, merge bases and patch
checks. Example commands (no network or model calls):

```sh
git merge-base b5f7eac 33fb30a
git rev-list --left-right --count 33fb30a...803eb78
git cherry -v 33fb30a 6c883f3
git diff 33fb30a 803eb78 -- loom/src/chat/active_task_spec.cpp
git ls-tree -r --name-only b5f7eac
git worktree add --detach ../chatadhd-archived-night 33fb30a
```

An archived worktree reconstructs the original paths and committed byte content;
its receipts provide commands and runtime details. Credentials and unavailable
private source bytes cannot and must not be reconstructed by publishing them.
The public repository must not receive such data during consolidation. Original
inputs that were never committed remain an explicit recovery limitation.
