# Raw actor-label projection diagnostic protocol

This is a separate posthoc mechanism hypothesis on the frozen current-native first outputs, not a new native/model experiment or blinded source-graph quality study. The24 DEV sources,84 native primary observations and original raw metadata have already been inspected. Existing native source output/code/pack/freezes remain unchanged. No native rerun, network/API, new validation, old holdout or gold is used.

Hypothesis: the derived observation's named actor is absent from its speaker field (native baseline0/84 under the declared user-role source projection), while an exact locator into preserved raw source can still expose a source-recorded actor label, with explicit unknown/conflict behavior and no cross-source identity merge. This does not verify a real person, assert same_as across equal names, or create a second native graph.

Inputs: all84 primary native observations from all24 cases and both native arms' full48-case ledger. The malformed literal-role arm has0 native observations and stays an explicit zero-availability control; no imaginary observations are supplied to the projection. Each existing observation is bound to the exact input container SHA256, supported OpenAI message pointer and UTF8 source quote. These input/first-receipt hashes are frozen before projection outputs.

Recipe is data: actor label from author.name and message.metadata.loom_source_speaker, only after exact source binding. Equal present scalar labels resolve; a single present label resolves; missing labels stay unknown, malformed scalar types/empty labels are invalid, conflicting labels abstain. User/assistant transport roles never act as a fallback actor. Source ID must agree between document/message metadata. Turn IDs must agree between mapping key, message ID and source metadata. Source-known_at statement must be explicitly present and agree with source create_time and native observation date; missing orNone stays unknown without epoch/observation-date imputation. This preserves a literal source statement, not temporal truth.

Per-field states remain separate. A conflicted source ID does not become a global actor/node association; outputs retain raw-source hash and message pointer even when another field abstains. There is no global name-based merge, same_as edge, graph mutation or claim-status change. Native speaker and transport role remain in the projection receipt. Actor epistemic status is source_recorded, never verified identity.

Primary measures:84 observations planned; exact-bound projections; each declared field's resolved/unknown/conflict/invalid count; fully resolved projections; native named-actor baseline0/84, versus recoverable literal actor labels under this one source-wrapper recipe. No relation precision/recall, world-identity accuracy, or model accuracy is measured.

Control measures: independently authored toy transport controls, frozen before their first projection, exercise actor conflicts/missing labels, conflicting source IDs, equal turn IDs across different sources, missing/malformed locators, narrow UTF8 quotes, source-known_atNone, date conflicts and source-hash drift. A field conflict must abstain; name equality across raw sources must not collapse source namespaces. Retain every first control result, its exact raw serialization/hash and expected states. Mechanism tests are distinct from measured recovery on the existing native source records.

Decision rule: keep only if all84 source bindings remain exact, native/raw inputs remain immutable, actor recovery retains declared source labels without role substitution, and negative controls show explicit abstention/namespace preservation. Investigate any source-binding failure; do not weaken the contract or tune source-case exceptions. A positive result motivates a graph projection capability design, not automatic production integration.
