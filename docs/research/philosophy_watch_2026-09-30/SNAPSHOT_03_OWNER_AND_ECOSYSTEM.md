authorised cheap/Jev programme under the existing nonresetting USD 2 dedicated

priorities. Bidirectional capability sharing and reusable memory do not require
ChatADHD to mediate every operation. ChatADHD can optionally interface with AGEDS
and WatchDog; iOmatrix and other projects can use knowledge independently.

The Loom invariant of one source graph with multiple projections is scoped to
that semantic domain. It does not force all ecosystem applications into one
database, repository, technology or graph semantics. An adapter should carry its
semantic contract, source references, known_at, and representation-loss receipt.

Loom's meaning. Sharing context is separate from granting execution access.

Concrete next experiments remain offline mechanisms: two-way adapter roundtrip
with an explicit loss ledger; graph clipboard across distinct semantics; context
sharing with denied action permission; correction memory usable without chat;
and source-bound hypothesis transfer preserving model origin and alternative
interpretations. Baselines are identity pass-through, explicit refusal to map,
and the original source packet. Keep a mapping only when all declared retained
properties survive; represent unresolved meaning as alternatives, not certainty.
