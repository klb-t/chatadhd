# Philosophy watch: first mechanism audit protocol

Frozen intent, 2026-09-30. This audit owns only this directory. It makes no API
calls, reads no credentials or sealed validation/holdout, edits no production
code and does not manufacture a model-quality score. The examples below are
new, deliberately authored counterexamples, not an independent natural corpus.

Question: do the current candidate graph operations preserve the project's
epistemic distinctions, and where can a consumer infer more than the mechanism
actually proves? The primary measured unit is one named deterministic check.
All first outputs, including exceptions, are retained. Existing first experiment
scores are never rewritten. Keep/revert/investigate refers to a research method
or interpretation; this audit has no authority to promote a candidate graph.

Pre-outcome checks:

1. Query payloads physically exclude turns after the requested cutoff; appending
   a future turn must not change an earlier raw-source query body.
2. Candidate compilation, individual-source projection and formal inference do
   not mutate source inputs or supplied candidate records.
3. Byte and character source locators agree for accented Polish and emoji.
4. Absence of an explicit edge gives unknown, never an invented refutation.
5. A directed edge does not create its reverse or contraposition. Negated
   proposition identifiers remain opaque.
6. An alternative-path inference keeps all incomparable support paths and their
   premise IDs and remains inferred with unverified world content.
7. An extrapolated row must be rejected as a formal premise; no fake confidence
   is filled in when it is unavailable.
8. A same-source supersession may change a derived current-commitment view; a
   cross-source candidate event stays in the audit while being withheld there.
   Both the old and new source assertions stay in the original graph.
9. Null-replacement withdrawal is unsupported by the older direct ABI and must
   remain explicitly unavailable, rather than be encoded as a negative edge.
10. An exact source locator alone can still bind a semantically unsupported
    reverse relation or arbitrary attribution. This is an expected diagnostic
    counterexample, not a compiler regression or a model-quality measurement.
11. Graph source time is not model claim availability. Derived lookups must
    expose retrospective scope and semantic verification false.
12. Check whether a malformed or cross-speaker *future* event can affect a past
    formal query. A change/exception diagnoses whole-graph validation dependence;
    it does not by itself establish a paid model's future-knowledge leakage.
13. A search bound that prevents complete alternative-path enumeration must
    report unavailable/incomplete; a conflict must remain visible under the
    declared formal policy.

Before execution, save code hashes, protocol hash, local repository commit and
UTC timestamp. Run without API/key environment variables. Save every named
check's result and trace in `FIRST_MECHANISM_RESULTS.json`. A failed invariant
or diagnostic result is investigated in a new snapshot, not silently edited.

The complete original chat that generated the session prompt was not available
to the parent agent; available source documents and saved windows, rather than
an invented transcript, define the reviewed contract. This audit reads current
repository sources and the visible user instruction to broaden frontier,
prompt-variant and agent-based research. The newly mentioned Claude note is
