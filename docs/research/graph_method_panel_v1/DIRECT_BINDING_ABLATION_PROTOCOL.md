# Direct lookup: citation binding ablation protocol

Frozen before this ablation's predictions and labels are joined. This is an
outcome-informed DEV follow-up to direct lookup's first 88/96 result and to the
independently preserved turn-reference replay. It is not blind validation and
uses zero new model calls. Do not read sealed validation.

## Hypothesis, one variable, and control

Replacing model-copied quotes with unchanged full source turns under explicit
valid turn IDs may recover mechanically rejected assertions and consequently
their status events. Compare the same 96 fixed DEV queries through the exact
unchanged direct lookup code and policy against the two already preserved graph
compilations of the **same raw model responses**. Only the upstream evidence
binding basis differs: original exact model quote versus the frozen opt-in
`turn_reference_binding_v1/first_results/compiled_binding_first.json`.

Do not change attribution, actor/event authority, temporal decision, predicates,
node IDs, polarity, correction convention, or gold. Full-turn binding establishes
a source locator, not semantic justification. Retain original raw responses,
model quote hints, source bytes/times/spans, and all compiler outputs. Each new
prediction names `turn_id_full_source_copied_by_deterministic_binder` as its basis
and copies the preserved case provenance sidecar without using it for decisions.
Hints including wrong/future hints stay model hints; source binding is not proof.

GPT extraction used full conversations, so both arms remain retrospective
source-cutoff projections. They are not causally prefix-extracted or information
equivalent to raw prefix judges. Source known_at does not equal model claim
availability. No canonical graph or source is modified.

## Freeze, evaluation, and decision

Freeze the original direct contract, both first baseline outputs, new adapter and
tests, this protocol, binding graph/provenance/raw model content/source freeze,
and binding implementation/policy before generating any new predictions. The
original direct contract must still exactly reproduce its frozen hashes.
Verify the upstream binder's pre-gold five-artifact receipt, its replay freeze,
and every recorded source/response/dependency hash before predictions; reject
drift rather than create a newly authorized experiment over changed bytes. Save
all 96 predictions before loading DEV gold. Then reuse the primary scorer and
require the original 88/96 score dictionary to reproduce exactly.

Preserve first confusion/per-class TP, FP, FN and separate precision/recall
denominators, coverage/unavailable, all failures and changes, family/language
groups, paired both-correct/binding-only/original-only/both-wrong counts. Carry
the oracle graph's existing 96/96 score separately as a mechanism control, not
new extraction quality. Neither the oracle nor gold controls predictions.

Keep the binding arm as an opt-in candidate if it restores intended mechanical
availability without changing previously correct decisions or losing traceable
hints. If primary quality or availability regresses, preserve the full first
outcome and investigate rather than edit this freeze. A gain diagnoses a binder
failure in this development replay; it does not establish generalization,
semantic adequacy, or a global model ranking.
