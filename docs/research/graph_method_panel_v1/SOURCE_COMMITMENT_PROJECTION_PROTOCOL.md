# Individual-source commitment projection: DEV protocol

Preregister before this projection's predictions, after citation-only DEV lookup
scored 92/96. This is an outcome-informed development ablation, no new model/API
calls or sealed validation. Preserve both earlier 96-query runs and their exact
code/policy/contracts.

Hypothesis: when querying **individual source commitments**, one attributed
speaker's denial must not silently supersede another's older commitment. Change
one explicit data policy: application of superseded events in the derived view
requires exact equal `attributed_to` strings on old and replacement assertions.
Do not invent identity aliases or general world-authority rules. This policy is
scoped to `source_scope=individual_source_commitment`, not a claim that different
actors can never issue authoritative corrections in other domains.

Use the frozen citation-bound graph of the same raw model responses; assertions,
evidence, IDs, source timestamps and raw status events remain immutable. A pure
deep-copy helper withholds cross-source events only from the queried projection.
Every raw candidate event stays in a separate case audit with original content,
withheld reason and candidate index. Keep model extraction/event-quality scores
and denominators unchanged: a view policy cannot erase extraction false positives.
Malformed records are delegated unchanged to the original lookup rather than
made valid by projection. No actor/phrase/gold filter removes a typed assertion.

Freeze data policy, new helper/driver/tests, this protocol and the complete prior
citation freeze and first outputs before predicting the 96 fixed queries. The
unchanged original lookup performs matching/temporal/source binding over the
derived view. Keep all binding hints and raw event provenance, mark world authority
unverified, and preserve source-binding versus semantic-proof distinction. Whole
conversation extraction remains retrospective; causal prefix independence and
information equivalence with raw prefix judges are false.

Save predictions before DEV gold join. Reuse the primary scorer; require exact
92/96 baseline dictionary reproduction, report precision/recall denominators,
confusion, availability, all new gains/losses and paired counts. Preserve raw and
withheld event counts by case. Do not present oracle/empty graph controls as model
quality or tune this policy after outcomes. Mechanism tests cover same-actor
correction, cross-source withholding with raw preservation, unknown identities,
nonmutation, malformed delegation, cutoff and alternative replacement.

Keep as a named optional source-commitment projection if no earlier correct
decision regresses and meaningful countercases pass. Investigate any loss or
scope contradiction. Even a gain here does not prove generalization: upcoming
validation families do not independently test temporal/cross-source authority.
