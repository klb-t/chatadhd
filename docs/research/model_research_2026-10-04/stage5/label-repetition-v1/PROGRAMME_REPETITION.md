# Exact request repetitions and supplied-source label replay

The generic helper accepts a source programme manifest, exact request artifacts,
a hash-bound selection document and caller policy. It assigns a distinct operation
ID to every configured `(repetition, query, arm)` cell. Bytes, model/provider route,
unit upper bounds, minimum reservations and prompt hash are preserved. A repeat is
a new scientific observation of the same authored DEV query; it is not a retry or
replacement of a failed first answer. The original operation ID remains bound in
metadata. Count, selection membership, population and execution order are data.
No new corpus is created, and preparation does not read gold labels or model replies.

The current label-task preset is two repetitions of the two previously selected
arms on all 48 original query IDs, paired by repetition/query/arm: **192 new planned
operations**. It binds the existing source-label task selection; it does not claim
a winner for native extraction or for groups with unresolved semantic dimensions.
The supplied public source manifest is an offline equivalent generated by the
unchanged standard manifest adapter from all original prepared requests. It contains
no key, account metadata, ledger or actual reply. Root may recreate it with that
adapter and bind the resulting exact source hash as caller policy data.

Every planned request remains in scoring denominators, including missing,
malformed, conflicting and failed first responses. The unchanged pure Jev compiler
and panel scorer are used for each repetition and for pooled observations.
Derived pooled query IDs explicitly qualify the repetition; query IDs inside sent
bodies remain unchanged. Input row/capture duplicates are rejected, so a successful
later answer cannot replace a failed first one. Unknown billing remains null and
has an explicit count; a known-cost subtotal is never described as the total when
any cost is unknown. Source-label agreement and billing availability are separate.
Label-eligible response states are caller DATA; this preset allows completed and
pending_billing rows only when the first HTTP 200 capture, source request, model,
reported cost and unique generation ID are bound and valid. A pending credit bill
remains null until generation proof is verified. Failed and ambiguous rows remain
unavailable; eligibility does not grant transport or billing completion. Native
grounding, semantic adequacy and world-truth accuracy remain UNKNOWN.

An optional caller-configured family cluster bootstrap keeps all repetitions of
one source family together. It is disabled in the current preset. It does not
turn reused authored DEV into independent or blind holdout evidence.

The scorer consumes public normalized receipt attestations and selected first-response
projections; it does not re-read private HTTP/generation bytes. Its output records
this boundary and exact input/source/manifest/compiler hashes. Live key, cumulative
billing and fresh pair-price/FX admission belong to the existing paid runner. The
192 historical minimum floors total USD 0.192; the actual forecast must use current
pair-specific prices, dated FX and the cumulative budget gate before dispatch.

After source freeze, the root coordinator can use:

```sh
python -m loom.tools.structure.research_programme_manifest adapt-analysis \
  docs/research/analysis_optimization_2026-10-02/prepared \
  --output /path/to/public-equivalent-source \
  --programme-id stage1-public-equivalent-20261005 --stage-id original-label-queries
python -m loom.tools.structure.programme_repetition_v1 prepare \
  --source-manifest /path/to/public-equivalent-source/manifest.json \
  --selection /path/to/frozen-selection.json --policy /path/to/bound-policy.json \
  --output /path/to/repetition-plan
python -m loom.tools.structure.programme_repetition_v1 verify \
  --source-manifest /path/to/public-equivalent-source/manifest.json \
  --selection /path/to/frozen-selection.json --policy /path/to/bound-policy.json \
  --manifest /path/to/repetition-plan/manifest.json
python -m loom.tools.structure.programme_repetition_v1 score \
  --source-manifest /path/to/public-equivalent-source/manifest.json \
  --selection /path/to/frozen-selection.json --policy /path/to/bound-policy.json \
  --manifest /path/to/repetition-plan/manifest.json \
  --bundle /path/to/public-normalized.json --gold /path/to/hash-bound-gold.json \
  --output /path/to/label-repeat-score.json
```

`prepare` performs no POST. The root coordinator alone dispatches through the
unchanged runner after review and the full test gate. First captures and credit
proofs are normalized by the existing receipt adapter. This module cannot grant
paid-call authorization or select a replacement answer.
