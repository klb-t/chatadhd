# Hash-bound context preparation DATA producer

This standalone research producer substitutes only configured JSON pointer locations in exact public templates. Explicit input/template/floor/selection files are raw-hash bound. Population, methods, order, expressions, prepared schema, final row digest field and preserved body pointers are JSON DATA. No model/case/story names, price assumptions, output limits or quality thresholds occur in the generic producer. There is no network access or automatic input discovery.

Expressions can preserve values, serialize canonical JSON or compute canonical SHA256. Every method's case inventory is exact; input key allowlists can exclude undeclared fields. Actual adapted request body hashes must match the computed context-bound bodies, so a row template cannot omit updates while claiming them in a receipt. Whole-row digest fields are recomputed last, separately from body hashes. Caller experiment namespaces are preserved; ephemeral directories do not affect IDs or recorded source paths. A custom prepared rows key uses a separately recorded legacy transport projection.

The 21 invented tests cover Unicode, parameter/provider/schema preservation, source-hash failures, explicit selection/population/order, no sibling gold/rubric discovery, key allowlists, pointer failures, stale row/body claims, finite source floors, atomic collisions and byte replay. The existing evaluator's prepared/body/response binding checks are exercised with a mocked semantic instrument; no semantic verdict is invented.
