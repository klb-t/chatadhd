# Role-explicit source-view representation, diagnostic development

Registered after the two SourceView first measurements were available and before
any role-explicit model output. This is a separate representation experiment;
neither prior output is renamed as a result of this recipe.

## Question and controlled variable

The active-refutation recipe scored 45/48 on the targeted development panel.
Its remaining errors included withdrawal of A→B misread as refutation of B→A,
and withdrawal of a denial misread as an active denial after an irrelevant turn.
Hypothesis: explicitly expanding the requested relation's source and target
propositions in the state may reduce endpoint-role mistakes.

The only intended model-input variable is state representation. The original
canonical query payload is preserved byte-for-byte as `source_record` in a new
outer object. A redundant `requested_relation_roles` card copies the requested
relation, complete source/target node records, attributed speaker, cutoff and
scope. No proposition is paraphrased; no negation/operator is rewritten; no
source turn, inventory alias or provenance is removed. Future turns remain
physically excluded by the unchanged prefix operation. The card adds no claim
that the relation is supported, false or absent.

q01, q02, their instructions and criteria, insertion order, model/provider,
threshold strictly greater than 0.5 and the three-class compiler are unchanged
from `active_refute_v2`. All 48 planned query IDs are retained. No retrieval
channel, heuristic or observed answer gates this representation.

This intervention adds redundant information and changes state length and
nesting together. It measures the whole representation recipe, not a causal
effect of any single field name. Twelve bilingual conversations are correlated;
this authored diagnostic panel cannot estimate population performance.

## Evaluation and integrity

Before consulting any reference labels, preserve compiled first outputs and
execution summary. Score full confusion and precision/recall separately for
supported, refuted and unknown; denominator remains 48 including missing,
rejected or conflicting responses. Compare the three remaining active-baseline
errors, all regressions, language/family profiles, unchanged-q01 probabilities,
actual input tokens, cost and recorded request timer separately.

The wrapper reconstructs the whole ordered expected inventory, binds model
aliases and snapshot hash to the public endpoint snapshot, retains all billing
artifacts and hard-fails raw/ledger discrepancies. It validates the pre-call
freeze before scoring. Missing BYOK flags remain the inherited parser's
limitation; an explicit true flag is rejected. Source commitments concern what
a speaker states, not world truth. This research projection performs no graph
promotion or canonical writes.

Keep as a tested experimental representation if actual model measurements
improve errors without masking regressions. Investigate gains accompanied by
losses or contradictory probabilities. No threshold/gold tuning, silent retry
or unregistered extra model call belongs to this protocol.
