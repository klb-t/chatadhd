Real offline replay passed on 2026-10-04. The production dictionaries moved from
C++ to the Pack `cues.classes` data without changing their default numeric values
or phrase order. No model provider was used.

Default native records are compared as parsed JSON, including all score and
typing fields, rather than asserting identical JSON whitespace/number notation.
Deletion intentionally changes the legacy resurrection behavior.

The runner compiled exact public pre-change `common.cpp`, `principles.cpp`,
`internal.h` from commit `50e6bb9f80b0cd855e4dd1efedaf3399cac5e4e6` and a frozen
copy of their current counterparts. Both pairs were linked before the same
prebuilt core archive; old/current cues were passed explicitly through real
`Pack::from_documents`. The listed source and archive hashes were captured before compilation
and checked again after both runs. The summary contains those hashes plus
object/executable/raw-result hashes. The raw controls and command log are kept
next to this proof; filenames have `dic0301_` added to the original scratch names.

```sh
python3 loom/src/generalize/tests/dic0301_replay.py \
  --core-build loom/build/dev \
  --output /tmp/dic0301-replay
```

The output directory must be fresh. The pre-change pin must exist locally.
`CXX` may choose a compiler; compilation remains serial.

This proves the tested source-level preservation/configuration behavior, not a
new graph accuracy gain or full merged CTest. The public DEV loader and corpus
files are identified by the repository/pin and replay code but are not included
in the before/after input-hash assertion; no complete corpus freeze is claimed. The prebuilt archive did not need
to embed the new cue data for this paired replay; the generated Pack must still
be rebuilt and checked by normal `test_kb_pack`/full CTest. Root owns those gates.

The unchanged foundation Pack validator requires nonempty cue lists and rejects
`phrases: []`. We do not claim an accepted empty-class disable. Removing a class
is accepted and now disables its matches without a C++ fallback. Complete
replacement does not merge the old semantic dictionary. Foundation follow-up:
permit a standard empty-list disable if the profile API requires it. Whole-profile
permanent exclusions/tombstones (R40) and R39/R41 inference/observation semantics
remain separate tasks. The public generalize header's old fallback comment is
outside this edit ownership and still needs its owner's update.

First positive preview is preserved in scratch `dic0301-native-1`; its source-byte
freeze was superseded because whitespace cleanup overlapped compilation. This
final proof uses frozen copied sources and checks stable hashes throughout.
