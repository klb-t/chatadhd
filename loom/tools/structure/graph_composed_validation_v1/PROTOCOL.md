# Frozen source-graph composition transport

This module receives cases from the coordinator. It never loads a fixture input
or answer file, never accesses a key, and never calls a model. The new sealed
graph-panel validation inputs and gold remain unread while this wrapper is
implemented and mechanically tested. Owner instructions currently defer paid
synthetic pilots and validation calls; this wrapper does not authorize them.

The coordinator must obtain an externally pinned `VerifiedRelease` from the
unchanged `graph_panel_validation.authorize` before any actual sealed access.
`extraction_records(cases, batches, release)` requires that ticket, invokes the
unchanged replay checks for every complete planned assisted-extraction batch,
then obtains original GPT content through the unchanged provider/billing parser.
The full case inventory must occur exactly once across those batches. Missing,
failed and unattempted rows remain present. Billing discrepancies remain fatal;
they cannot become semantic abstentions. Public Jev version pins and inherited
budget/unknown-reservation checks remain the responsibility of the existing
validated release wrapper. No new price, model or budget is introduced.

`predict_cases` accepts supplied records and has **no gold argument**. Original
compilation is replayed exactly; any disagreement is fatal. Three separate
variants are saved without modifying the raw candidate graph:

1. original quote compiler and original direct lookup;
2. unchanged turn-ID citation binding, original compiler, original lookup;
3. the citation-bound graph projected through the unchanged individual-source
   commitment policy, with raw events/withheld-event audits preserved, then
   original lookup.

The frozen formal operator is applied independently to each graph variant only
for `formal_implication` queries. Those results never enter the explicit-source
judge denominator. All formal alternatives are retained; operator rejection or
bounded search is unavailable, with planned denominators preserved. Inference
remains conditional on supplied premises, with `basis_class: inferred`, exact
premise provenance and `content_truth: unverified`. Negative propositions are
opaque IDs; no contraposition or semantic supplementation is added.

All variants are **retrospective full-conversation extraction followed by source
cutoff**. Source `known_at` is not model-claim availability. They are not equivalent
to physically prefix-limited raw-source judges, and this wrapper cannot establish
causal future independence. Source binding is not evidence of semantic truth.

Before any gold is supplied, `predict_cases` writes exclusively a new directory:
supplied input cases, original raw model contents/hashes, all compiled variants,
binding derivations/provenance, source-projection audit, all first predictions,
and a complete `freeze_before_gold.json` hash inventory. Existing artifacts are
never overwritten. The coordinator supplies gold only afterward. This order is
enforced mechanically for file integrity, not as a claim of human memory blindness.

Evaluation independently recomputes every first artifact from the preserved
cases/model contents and compares the complete inventory before loading any
metric. It reuses unchanged strict extraction and judgment algebra. Extraction
quality is measured for original and citation-bound compilers only. The source
projection is a view, not a repaired extractor, so it cannot erase source-event
errors from the extraction denominator. Explicit-source and formal-label metrics
are separate, including confusion matrices, per-class precision/recall and
availability. Missing/conflicting results do not disappear.

Formal path measurement freezes this correspondence rule before any validation:
each predicted premise maps to a gold premise only when the existing strict typed
key and validated evidence-turn subset identify exactly one gold assertion. No
best-fit, text similarity or semantic matching is used. Unmapped premises receive
a disjoint diagnostic ID. Ordered mapped path IDs are counted as a multiset:
matched path TP, extra/duplicate path FP, missing path FN. The unique premise
union is scored separately for each query before sums across queries. All
alternative preservation requires no missing/extra paths and a completed result.
These are alignment-dependent measurements, not world-truth claims. Empty gold
support sets retain query denominators and undefined precision/recall where
appropriate. Unknown/no-path is not refutation.

Synthetic tests exercise dispatch, missing records, quote repair, cross-source
projection, formal alternatives, unmapped premises, unavailable denominators,
exclusive first-file persistence and drift rejection. They measure the mechanism,
not the quality of any model. No sealed validation files, older blind holdouts,
network or credentials are used.
